<original_problem_statement>
The project began as **FITTR**, a location-based fitness social platform. It was then pivoted to **GOWITHME**, a social connection app with a hybrid Uber/Facebook feel, a dark blue theme, and a map-centric UI. The user has since provided further instructions, renaming the app to **WannaGo** and providing a series of detailed feature requests and UI refinements for various pages.

**PRODUCT REQUIREMENTS (Current):**
- **App Name:** WannaGo
- **Core Concept:** A map-based social platform to connect users for activities, split into Athletic and Non-Athletic categories.
- **Core UX Flow:**
    1.  **Home/Dashboard:** A 50/50 split view with a map and an activity panel. User selects a category (Athletic/Non-Athletic), then a specific activity from a text-only dropdown.
    2.  **Connection Type:** User selects a connection type (Buddy, Trainer, Competitor, Group, Accessible).
    3.  **Broadcast:** User refines the search with a radius slider and advanced filters (intensity, injury considerations, etc.). The Broadcast button text is dynamic (e.g., Find A Running Trainer). A Spreading the word... loading state is shown.
    4.  **Find Companion:** A list/map of matching users is displayed.
    5.  **Meetup:** During the meetup, a user must have a way to cancel at any time for safety, with an option to leave a review explaining why.
- **Key Features Requested:**
    - **Fixed Bottom Navigation:** Always visible.
    - **Back Buttons:** A universal back button on all main pages.
    - **Profile Page:** Users can upload shareable/private photos and videos, and set an activity status.
    - **Activity Log:** An editable My Availability calendar with public/private options. Interactive activity cards allowing users to add checklists, location info, and comments that get included in broadcasts.
    - **Rate Experience Page:** Ability to upload photos and short videos (under 30s) in reviews, with an option to share on social media or the app profile.
    - **Wellness Store:** A redesigned page with category navigation and featured item grids, intended for a future Shopify dropshipping integration.
    - **AI Workout Generator:** This feature has been explicitly **removed** by the user.
